# TypeScript Git Graph Visualizer (`ts-git-visualizer`)

An interactive browser-based Git commit history visualizer and Directed Acyclic Graph (DAG) renderer built with React, TypeScript, and Tailwind CSS.

## Features

- **Interactive Commit Graph:** Renders real-time SVG connections between parent commits and branches.
- **Branching & Checkout:** Create new feature branches, switch active branch HEAD pointers, and execute commits.
- **Strict TypeScript Types:** Complete interface mapping for Commits, Branches, and Graph Nodes.
- **Tailwind CSS UI:** Responsive dark mode layout styled for technical clarity.
